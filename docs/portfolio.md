## LinkedIn — Français

J’ai développé une plateforme MLOps de prédiction du churn couvrant l’ingestion, la validation des données, la sélection de modèles, le suivi MLflow, le serving FastAPI et le monitoring Evidently, avec un dashboard Streamlit.

Sur le jeu public UCI Iranian Churn, XGBoost atteint une ROC-AUC de 0,9862 et un F1 de 0,8571 sur 570 observations de test. Une attention particulière a été portée aux doublons : les profils identiques restent dans une seule partition pour éviter les fuites de données.

Le projet comprend 21 tests automatisés, une orchestration Docker Compose et des workflows GitHub Actions. Les vérifications réellement exécutées et les limites sont documentées dans le README.
